Interpolation

Here is an important idea in animation. If you want to move something from one spot to another over a series of frames, you will need to figure out where to put that object

Write a class called Point and give it an initializer that sets the x and y values. Then, write a function called interpolate that takes three parameters, a, b, and n where

  • a and b are points
  • n is the number of steps. The output should be a list of n equally spaced points on the line from a to b.

For example, if we had this function the following code would give the following output.

pt1 = Point(1,1)
pt2 = Point(5,9)
print(interpolate(pt1, pt2, 5))

[(1,1), (2,3), (3,5), (4,7), (5,9)]

Op Art

In class, I showed you how to make an svg from a library, but that is not strictly necessary. You can simply print the svg directly. You just need to get the format correct and you can add other data in the right places.

x1 = 100
y1 = 100
x2 = 200
y2 = 50

print("<svg xmlns=\"http://www.w3.org/2000/svg\">")
print(f"<circle cx=\"{x1}\" cy=\"{y1}\" r=\"10\"/>")
print(f"<circle cx=\"{x2}\" cy=\"{y2}\" r=\"6\"/>")
print(f"<line stroke=\"black\" stroke-width=\"2\" x1=\"{x1}\" y1=\"{y1}\" x2=\"{x2}\" y2=\"{y2}\"/>")
print("</svg>")

Can you use this pattern and your interpolation function to make an image like the one we saw in classs that takes two lines of points and connects the first point in one line to the first point in the other line. Then it connects the second point to the second point and so on.
