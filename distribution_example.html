Distribution Example

Here is a simple example of using a dictionary to represent a distribution. Let's suppose we are trying to decipher some text. We know that someone has scrambled the alphabet. One way to get a guess at which letter is which is to see that the most common letters appear the most. To do that, we should first see which letters are most common in English. I will just grad a document with a bunch of text and count how many times each letter appears.

distribution = {}
alphabet = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"

for letter in alphabet:
    distribution[letter] = 0

with open("charles_babbage.md", "r") as f:
    for line in f:
        for letter in line.upper():
            if letter in alphabet:
                distribution[letter] += 1

L = []
for letter, counts in distribution.items():
    L.append((counts, letter))

L.sort(reverse=True)
print(L)

This is maybe what you expected. E is the most common letter, then A, then I, then N, et cetera. That's just for the file I opened. In general, the second most common letter in English is actually T. But, we only looked at one file. If we looked at more text, we would see different numbers.

The numbers we actually care about are percentages. For example, it is known that in English, the letter C appears 2.78% of the time. List we get the number 97 for C. We turn 97 into a percentage by calculating what fraction of all the letters is 97. When we make this change, we'll also tidy up our code and package it into a class.

class LetterDistribution:
    alphabet = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"

    def __init__(self):
        self.distribution = {letter: 0 for letter in self.alphabet}
        self.total = 0

    def add(self, letter):
        letter = letter.upper()
        if letter in self.alphabet:
            self.distribution[letter] += 1
            self.total += 1

    def prob(self, letter):
        letter = letter.upper()
        if self.total == 0:
            return 0
        else:
            probability = 100 * self.distribution[letter] / self.total 
        return f"{probability:02f}%"

    def __str__(self):
        table = [(v,k) for k,v in self.distribution.items()]
        table.sort(reverse=True)
        output = []
        for count, letter in table:
            output.append(f"{letter} : {self.prob(letter)}")
        return '\n'.join(output)


distribution = LetterDistribution()

files_to_read = [
    'lists.md',
    'dictionary.md',
    'nesting.md',
    'strings_and_print.md',
    'computer_architecture.md'
]

# We will loop over several files to see the results.
for filename in files_to_read:
    with open(filename, "r") as f:
        for line in f:
            for letter in line:
                distribution.add(letter)

print(distribution)

Sample from a Distribution

As we have seen, a distribution gives us a probability to for each thing. The technical term for these things are events. This makes sense espoecially if you are thinking about what is the probability of some event. In our specific example we stored letters, so each letter gets a probability.

A basic use of a distribution is to sample it. This means we want to extract a random item. The word random does not mean arbitrary. If we wanted an arbitrary item, the distribution could always give the letter A. Instead, we want it to work out that as we sample many times, the fraction of times we get each letter should be close to the probability.

We will use Python's random number generator in the random module. The randrange function will return a random number ine a range, where every number will come up with the same proabability.

Here is a function that uses randrange to give a random letter.

from random import randrange

def sample():
    ALPHABET = "ABCDEFGHIJKLMNOPQRWSTUVWXYZ"
    index = randrange(26)
    return ALPHABET[index]

for i in range(50):
    print(sample(), end="")
Output 
OTAWPIOCDWRUQRDUCGTWSMFVWMGCNRGKSKLIASNQQFMRWPQRBW

Notice that the sample function does not have any parameters. Despite not taking different inputs, it does produce different outputs. This is becuase inside, it is calling out to the random number generator. If we run this program again, we will get a different set of letters.

Why doesn't the sample function we wrote achieve our goal for sampling from a distribution?

Click to reveal.

The letters will all show up with the same probability. That is, if we sample 26000 letters, we will get about 1000 Ts and 1000 Zs. For the distributions we constructed from real text, we know there should be many more Ts than Zs.

Implementing a Sampling Algorithm

Here is some code to sample from a distribution.

from random import randrange
from distribution import LetterDistribution

def sample(d):
    ALPHABET = "ABCDEFGHIJKLMNOPQRWSTUVWXYZ"
    n = d.total
    my_random_number = randrange(n)
    count = 0
    for letter in ALPHABET:
        count += d.distribution[letter]
        if count > my_random_number:
            return letter

# Create a distribtion
D = LetterDistribution()
for letter in "AAAAABBBZZ":
    D.add(letter)

# Make a new distribution
newD = LetterDistribution()

# Sample from the first distribution and add them to the second.
for i in range(200):
    next_letter = sample(D)
    newD.add(next_letter)

# Compare the distributions.
for letter in "ABXZ":
    print(f"{letter}:{D.prob(letter)=} vs. {newD.prob(letter)=}")
Output 
A:D.prob(letter)='50.000000%' vs. newD.prob(letter)='43.500000%'
B:D.prob(letter)='30.000000%' vs. newD.prob(letter)='37.500000%'
X:D.prob(letter)='0.000000%' vs. newD.prob(letter)='0.000000%'
Z:D.prob(letter)='20.000000%' vs. newD.prob(letter)='19.000000%'

Notice, that the probabilities are close, but not exactly the same. In the code, we computed the newD distribution from 200 samples. If we used more samples, the distributions would start to look more and more similar.

Note: A better design would put the sample method inside the LetterDistribution class.

Random Numbers Are Not Really "Random"

The computer doesn't have a way to flip coins and generate truly random numbers. It has to simulate this with some interesting mathematics. The technical term is pseudorandom generator of PRG.

The idea is that we start with some number and then apply a function to produce the next number. That first number is called the seed.

Often, when we write a program, we want to get the same output every time. One example would be if you used random numbers to generate a design of some kind and you just wanted to tweak the design in some small way, you would not want to have a whole new design when you rerun the code. Here is how to fix the seed.

import random

random.seed(12)
print(random.randrange(10))
print(random.randrange(10))
print(random.randrange(10))
Output 
7
4
8

import random

random.seed(12)
print(random.randrange(10))
print(random.randrange(10))
print(random.randrange(10))
Output 
7
4
8

Both programs produce the same random numbers. You will have to run this code yourself to see that this is really true.

If you don't set the seed youself, you will get a different seed, every time you run the program. How do you think this can work. Where does Python go for a new seed?
