Functions

Last class, we saw how to define our own functions. It's really important to use the right words when talking about functions. Let's practice with the following function based on one we saw in class.

def yay(n):
    print(f"Yay{'!' * n}")
    if n > 0:
        morale = "High"
    else:
        morale = "Low"
    return morale

print(f"yay has type {type(yay)}")
print(f"yay(2) has type {type(yay(2))}")
print(type(yay(2)))
Output 
yay has type <class 'function'>
Yay!!
yay(2) has type <class 'str'>
Yay!!
<class 'str'>

The code above is the definition of the function. The variable n is called the parameter of the function. The word yay is the name of the function. You can check the type of yay the same way you can check the type of any other function. The word class means type.

Thinking about what type of objects you have is the best way to begin understanding a complex program.

You can think of it as a variable. The variable morale is a local variable. It is not defined outside of the function. If we call the function twice, it doesn't remember what it was the last time the function was called.

The value of morale at the end of the function will be the return value. The value of yay(2) is "High". It prints something to the screen, but that is not how the function gives us its output. The output of the function is the return value. This is confusing at first. The key is to remember that a function gives its output to the program. When it prints, it's giving output to you. That's considered a side effect.

Repeat this out loud enough times to never forget it: Printing is not returning.

An Algebra Example

The general equation for a line in the plane is

\[ax + by = c\]

A specific example might be

\[2x + 3y = 0\]

or

\[5x - 4y = 6\]

The line defined by this last equation is the set of points $(x,y)$ that make the equation true. So, for example, the point $(2,1)$ is on this line because

\[5(2) - 4(1) = 10 - 4 = 6.\]

There are other points on this line as well. For example, $(1, -\frac{1}{4})$ is on the line:

\[5(1) - 4\left(-\frac{1}{4}\right) = 5 - (-1) = 6.\]

There are infinitely many points on the line. One way to identify them is to give a value for $x$ and then find the value for $y$ that lands on the line.

Write a function that takes a parameter x and returns a value y such that x,y is on the line 5 * x + 4 * y == 6. Here is a skeleton for your function:

def y_from_x(x):
    y = ????
    return y

How will we check that our program is correct? We can do some examples by hand. We can also write a function to check an answer.

Write a function check_answer that takes x and y as inputs and returns True if the point x,y is on the line. Otherwise, return False.

Finally, you can use your functions together to test your code as follows.

for x_test in range(100):
    y_test = y_from_x(x_test)
    correct = check_answer(x_test, y_test)

Lists

In Python, you can define a list of values. The simplest way to do this is as follows.

mylist = [2,3,5,7]
print(f"mylist has type {type(mylist)}")
Output 
mylist has type <class 'list'>

In this case, we defined a variable named my_list and we assigned its value to be a literal list. Recall that a literal is when you simply write down the value without having to compute anything on the right hand side. In the code above, we checked the type of and saw it is a list.

See the notes on lists for more details.

We access the items in a list using an index. The index is placed in square brackets after the name of the list (with no spaces between).

L = ["a", "b", "c"]
print(L[0])
print(L[1])
print(L[2])
Output 
a
b
c

The plural of index is indices. The indexing starts at 0. This is confusing at first, but you will grow to love it. Hopefully, the example below gives you a sense of the why this zero-indexing is a good idea.

Prime Numbers


In class, we checked if a number was prime by seeing if it is divisible by all smaller numbers.
This was overkill.
It would have been enough to check if it's divisible by all smaller primes.
In fact, even that is too many computations, because any number that isn't prime will be divisible by a number that is at most its square root.
Do you see why that is true?


So, for numbers up to 100, it suffices to check if they are divisible by the primes up to 10.
We can use this idea in the following program that prints all the 2 digit prime numbers.


primes = [2,3,5,7]
for n in range(10,100):
    n_is_prime = True
    for factor in primes:
        if n % factor == 0:
            n_is_prime = False
    if n_is_prime:
        print(n)
