For Loops

Doing Something Five Times

for i in range(5):
    print(i)

0
1
2
3
4

A for loop runs the same code once for each item in a sequence. The first line is the loop header, and it ends with a colon. The indented lines under it are the body of the loop. Python uses the indentation to tell where the body ends, so the indentation is not just for looks.

for i in range(3):
print(i)

File "<stdin>", line 2
    print(i)
    ^^^^^
IndentationError: expected an indented block after 'for' statement on line 1

Leaving out the indentation gives an IndentationError. Python expected a body and didn't find one.

Here, range(5) counts out the numbers 0, 1, 2, 3, 4. It stops just before 5. That looks off by one until you remember that indexing also starts at zero, from lists.

Key Idea: range(n) starts at 0 and stops just before n, so it gives you exactly n numbers.

The variable in the header is the loop variable. It gets a new value each time around. You can name it whatever you want.

for guess in range(3):
    print(f"{guess=}")

guess=0
guess=1
guess=2

You can also tell range where to start.

for i in range(1, 6):
    print(i)

1
2
3
4
5

With two arguments, it starts at the first and stops just before the second. I have found that range(1, 6) reads strangely at first. Say it out loud as "from 1 up to but not including 6" a few times and it sticks.

Looping Over a List

names = ["Ada", "Alan", "Grace"]
for name in names:
    print(f"Hello, {name}!")

Hello, Ada!
Hello, Alan!
Hello, Grace!

A for loop will walk through a list just as happily as it walks through a range. Each time around, the loop variable refers to the next item in the list. Notice that there are no numbers here at all. You never wrote a 0, and you never asked how long the list was.

Here is the same thing done the long way, with indexing.

names = ["Ada", "Alan", "Grace"]
for i in range(len(names)):
    print(f"Hello, {names[i]}!")

Hello, Ada!
Hello, Alan!
Hello, Grace!

It prints the same three lines. It is also longer, and it gives you two chances to make an off by one error.

Key Idea: If you want the items, loop over the list. Loop over a range only when you really need the positions.

Building Up an Answer

nums = [4, 8, 15, 16, 23]
total = 0
for n in nums:
    total = total + n
print(f"{total=}")

total=66

A variable that you set before the loop and update inside it is called an accumulator. The pattern is always the same. Start with an answer for the empty case, then let each trip through the loop improve it. Here the answer for no numbers at all is 0.

The list version from lists is the same pattern.

squares = []
for i in range(5):
    squares.append(i * i)
print(f"{squares=}")

squares=[0, 1, 4, 9, 16]

The empty list is the answer for the empty case, and each trip appends one more square.

Be careful to put the accumulator outside the loop.

nums = [4, 8, 15, 16, 23]
for n in nums:
    total = 0
    total = total + n
print(f"{total=}")

total=23

That resets total every time around, so at the end it only holds the last number. There is no error message for this one. The program runs happily and gives you the wrong answer, which is much worse.
