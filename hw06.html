        self.b = b

        if self.a.x == self.b.x:

You can use this library by saving it to a file. For example, if you call that file drawing.py you can import that file into another program. Say your other program is called opart.py, you might have the following in that file.

import drawing

fig = drawing.Figure()
p = drawing.Point(2,4)

Notice that when we import code, it gives us an object called drawing. That object has all the names in drawing.py as attributes. That's why we refer to the Point class by typing drawing.Point.

Python calls the drawing object a module. Any python program can be imported as a module. People often use the word module to refer to the file being imported. Techincally, one is the code and the other is the object that gathers all the objects defined by that code.

If instead you want to bring all these names into the current global namespace, you can import individual names as follows.

from drawing import Figure, Point

fig = Figure()
p = Point(2,4)

You can also just import everything using * like this.

from drawing import *

fig = Figure()
p = Point(2,4)

Be carefule about importing everything from a module unless you really know what's there. The module could have names defined that you want to use. You could overwrite them.

Default Values

Every SVG object has LOTS of parameters. There are many attributes that you could specify. Sometimes, you just want to let it use a default choice. There is a nice way to set a default value of a parameter in Python. You simply set it equal to something in the def line. The example above has a default value for line color. This means you can choose not to set a color and it will make that red color.

Be careful with default values. There are a couple pitfalls.

  1. All of the parameters that have default values must come after all the parameters that don't ahve defaults.

  2. If you have two parameters with default values, you cannot leave out only the first. The reason is that it will assign that last argument to the second to last parameter.

def foo(x = 3, y = 6):
    print(f"({x},{y})")

y = 100
foo(y)

(100,6)
  1. If you want to assign to just some of the parameters with default values, you can use the name of the parameter and an equal sign (like an assignment) in the function call.
def foo(x = 3, y = 6):
    print(f"({x},{y})")

foo(y=100)

(3,100)

  1. Pick a point inside the triangle and draw it.

  2. Pick a random corner of the triangle.You can put the corners in a list and choose one using randrange. As shown below, this will give you a random number in some range.
