4 A Hard Challenge

4.1 The Guesser

In class, we made a basic guessing game. Here was the code. In this assignment, we will add some features. Start by copying this code into a new program.

secret = 8

print("Guess a number from 1 to 10.")

guess = int(input())

while guess != secret:
    if guess < secret:
        print("Too Low. Guess again.")

    if guess > secret:
        print("Too High. Guess again.")

    guess = int(input())

if guess == secret:
    print("You guessed right!")

Let's make the number of guesses into a variable

Instead of just choosing from 1 to 10, let's let the secret be any number from 1 to $n$, where $n$ is some other number. Make a variable, called max_secret that stores the largest possible value for the secret. At first, you can set this value to 10 or whatever you like.

Let's put a limit on the number of guesses

First, let's decide on a good limit. If the numbers are chosen from 1 to 10, what is the smallest number $m$ such that $m$ guesses is always enough to get the right answer?

Add a variable to called max_guesses to determine the number of guesses you will allow.

Make the guess more random

The biggest problem with this game is that if you can see the code, you know what the secret is. There is a way to pick a random number in python, but instead, let's just obfuscate the number.

We will take the secret, multiply it by 1103515245 and then add 12345. You will end up with a big number, call it x. Take x % max_secret + 1 and the result will be a number from 1 to max_secret.

An advanced version

Can you figure out how to automatically set the number of guesses based on the max-secret value? You should make it so that it is always possible to win, but it requires careful play to win.
