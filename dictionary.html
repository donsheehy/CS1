Dictionaries

Overview

A dictionary is a kind of data structure that is used throughout Python and throughout programming in general. It stores pairs of things. The pairs are called key-value pairs because the first part of the pair is a key and the second part is a value. The main requirement that is enforced by the data structure is that only one item in the dictionary can have a given key. We express this by saying, keys are unique. The name of the dictionary class in Python is dict.

Dictionary literals are indicated with curly braces. (Remember a literal is when you just write the object directly, without constructing it with other functions.) The keys and values are separated by colons. The items (key-value pairs) are separated by commas. Here is an example of a dictionary literal.

D = {1: "one", 2: "two"}

In the example above, the keys are integers and the values are strings.

Here is another example:

d = {"hello" : 3, 2: "Goodbye"}

In the example above, we see that the keys are not the same type. The first key is a string, the second key is an integer. This is okay.

There are many examples of dictionaries that you have already used in Python. The most important one is a namespace. The keys are names, and the values are the objects that those names refer to. You can access the namespace associated with an object as follows.

class Foo:
    def __init__(self):
        self.secret = 4

f = Foo()

print(f.__dict__)
Output 
{'secret': 4}

Getting Values from Keys

The basic use of a dictionary is to get the value associated with a key. You give the key, you get the value. The notation uses square brackets, as in the following example.

D = {1: 'one', 2: 'two'}

print(D[1])
Output 
one

Assigning Values to Keys

Assigning a value to a key in a dictionary looks like a normal assignment. Again, the square brackets are used.

D = {1: 'one', 2: 'two'}

D[3] = 'three'
D[4] = 'four'

print(D)
Output 
{1: 'one', 2: 'two', 3: 'three', 4: 'four'}

Assignment Overwrites Old Values

If you assign the same key twice, the new value overwrites the old value. This is exactly the same as if you assign to the same variable twice.

D = {}
D['a'] = 100
D['a'] = 200
print(D)
Output 
{'a': 200}

The example above used an empty dictionary to start. The expression {} gives a dictionary with nothing in it.

Dealing with Errors

Common error when dealing with a dictionary is to look for a key that is not there.

D = {1: 'one'}

print(D[2])
Output 
Traceback (most recent call last):
  File "<stdin>", line 3, in <module>
KeyError: 2

The error you get is called a KeyError.

Here's a quick sanity check. You will not get a key error for an assignment to a key that doesn't exist. Why not?

Click to reveal.

The assignment creates a new item if the key doesn't exist.

There are four standard ways to deal with a KeyError.

  1. Check before you do anything.
D = {1: 'one'}
if 2 in D:
    print(D[2])
else:
    print("Oh no!")
Output 
Oh no!

Notice the keyword in is used here. It checks if the key is present or not. The expression 2 in D evaluates to True or False.

If you wanted to check that something was not present, the right way to do this is to use the not in keyword as follows.

D = {1: 'one'}
if 2 not in D:
    print("Oh no!")
else:
    print(D[2])
Output 
Oh no!
  1. Use the get method to return a default value when the key is missing. The second argument tells what to return if the key isn't there.
D = {1: 'one'}
print(D.get(1, "oh no!"))
print(D.get(2, "oh no!"))
print(D)
Output 
one
oh no!
{1: 'one'}
  1. Use the setdefault method to not only return the default, but also assign it in the dictionary. It behaves like the get method, but it also modifies the dictionary.
D = {1: 'one'}
print(D.setdefault(1, "oh no!"))
print(D.setdefault(2, "oh no!"))
print(D)
Output 
one
oh no!
{1: 'one', 2: 'oh no!'}

Make sure you see the difference between this one and the last one.

  1. Catch the error and do something else instead.
D = {1: 'one'}
try:
    print(D[2])
except KeyError:
    print("Oh no!")
Output 
Oh no!

This construction will run the first block and then run the second block if there is a KeyError. This same pattern is used for other errors.

Another word for this kind of error is an exception. The rule of thumb is that you should only use exceptions for exceptional situations. In other words, the try-except block is used only when you expect there to be no error most of the time.

Iterating over a Dictionary

The default way to iterate over a dictionary is to iterate over the keys.

D = {10: 'ten', 20: 'twenty', 30: 'thirty'}

for n in D:
    print(n)
Output 
10
20
30

There is a method that lets you iterate over the values. Note that it will repeat values if they are not unique.

D = {10: 'ten', 20: 'twenty', 'X': 'ten'}

for n in D.values():
    print(n)
Output 
ten
twenty
ten

You can also iterate over the key-value pairs. This is very useful.

D = {10: 'ten', 20: 'twenty', 'X': 'ten'}

for k,v in D.items():
    print(f"{k} is another way to write {v}")
Output 
10 is another way to write ten
20 is another way to write twenty
X is another way to write ten

Notice that we had to give two loop variables. You could also consider these one variable of type tuple. Parentheses make it more clear.

D = {10: 'ten', 20: 'twenty', 'X': 'ten'}

for (k,v) in D.items():
    print(f"{k} is another way to write {v}")
Output 
10 is another way to write ten
20 is another way to write twenty
X is another way to write ten

It is, quite literally iterating over tuples. You could do the following (even though you shouldn't).

D = {10: 'ten', 20: 'twenty', 'X': 'ten'}

for item in D.items():
    print(f"{item[0]} is another way to write {item[1]}")
Output 
10 is another way to write ten
20 is another way to write twenty
X is another way to write ten

Each item is a tuple. The first entry in the tuple (index 0) is the key. The second entry in the tuple (index 1) is the value.
