Comprehensions

A Pattern You Already Know

Here is a loop you have written many times by now. It builds a list of squares one item at a time.

squares = []
for i in range(5):
    squares.append(i * i)
print(squares)

[0, 1, 4, 9, 16]

This is the building-up pattern from for_loops and lists. Start with an empty list, loop, and append one item each time around. You will write this pattern so often that Python gives you a shortcut for it.

List Comprehensions

Here is the same list, built in a single line.

squares = [i * i for i in range(5)]
print(squares)

[0, 1, 4, 9, 16]

This is called a list comprehension. The square brackets on the outside tell you that the result is a list, just like a list literal. What goes inside the brackets is not a list of items. It is a recipe for making the items.

How to Read One

Here are the two versions side by side.

squares = []
for i in range(5):
    squares.append(i * i)

squares = [i * i for i in range(5)]

The loop header for i in range(5) appears in both, word for word, except the comprehension has no colon. The thing that got appended, i * i, moves to the front. The empty list and the call to append disappear, because the comprehension handles those for you.

I like to read a comprehension out loud like this: "a list of i * i, for each i in range(5)."

Key Idea: The part before for is what goes into the list. The part after for says where the values come from.

The part before for can be any expression. Usually, it will use the loop variable.

names = ["Ada", "Alan", "Grace"]
lengths = [len(name) for name in names]
greetings = [f"Hello, {name}!" for name in names]
print(f"{lengths=}")
print(f"{greetings=}")
print(f"{names=}")

lengths=[3, 4, 5]
greetings=['Hello, Ada!', 'Hello, Alan!', 'Hello, Grace!']
names=['Ada', 'Alan', 'Grace']

Notice that names is unchanged. A comprehension never changes the list it loops over. It builds a new list.

Filtering with if

Sometimes you don't want every value from the loop, only the ones that pass some test. For example, here are just the even numbers below 10.

evens = [i for i in range(10) if i % 2 == 0]
print(evens)

[0, 2, 4, 6, 8]

You can put an if at the end of a comprehension. It acts as a filter: only the values that pass the test make it into the new list. Here is the same thing as a loop.

evens = []
for i in range(10):
    if i % 2 == 0:
        evens.append(i)

The if keeps its place after the for, just as it sits inside the loop. You can filter and transform at the same time.

even_squares = [i * i for i in range(10) if i % 2 == 0]
print(even_squares)

[0, 4, 16, 36, 64]

Read it as "a list of i * i, for each i in range(10), if i is even."

Comprehension or Loop?

A comprehension is not a new power. Anything it does, you can already do with a loop and append. It is just a shorter way to write one very common loop.

I have found that the easiest way to write a comprehension is to write the for part first, then go back and fill in what goes in front of it. If you can't figure out how to say it as a comprehension, write the loop. And if a comprehension gets so long that you can't read it in one breath, the loop is probably the better choice anyway.

Dictionary Comprehensions

The same idea works for dictionaries (see dictionary). Here is a dictionary that maps each name to its length.

names = ["Ada", "Alan", "Grace"]
name_lengths = {name: len(name) for name in names}
print(name_lengths)

{'Ada': 3, 'Alan': 4, 'Grace': 5}

This is a dictionary comprehension. It uses curly braces instead of square brackets, and the part before for is a key-value pair with a colon in the middle. Read it as "a dictionary mapping each name to len(name), for each name in names."

Set Comprehensions

A set is a collection that keeps each value only once. Duplicates are simply dropped.

words = ["cat", "dog", "cat", "bird", "dog"]
print([len(word) for word in words])
print({len(word) for word in words})

[3, 3, 3, 4, 3]
{3, 4}

The first line is a list comprehension, so you get one length for every word. The second line is a set comprehension. It uses curly braces with no colon, and every repeated length shows up only once.

Key Idea: The brackets decide what you get. Square brackets make a list. Curly braces with a colon make a dictionary. Curly braces without a colon make a set.
