Setting Up Homebrew on a Mac

If you are on a Mac, the easiest way to install the tools we use in this course is a program called Homebrew. Homebrew is a package manager, which means it downloads, installs, and updates software for you from the command line. One command gets you Python. One more gets you Git. When a new version comes out, one more command updates everything.

Your Mac already comes with a version of Python and a version of Git, but they are old and Apple controls them. We want our own copies that we can update freely. That is what Homebrew gives us.

This note walks through the whole setup, start to finish. Read it once, then do it step by step. Nothing here can break your computer.

Key Idea: Homebrew is how you install and update developer tools on a Mac. Learn it once and you will use it for years.

1. Open the Terminal

Everything happens in the Terminal, which is the app that lets you type commands to your computer.

  1. Press Command + Space to open Spotlight.
  2. Type Terminal and press Return.
  3. A window opens with a prompt that ends in % or $. That is the shell, waiting for you to type.

If you have never used the Terminal, read navigating_the_file_system first. It covers pwd, ls, and cd, which are the three commands you need to move around.

2. Install Apple's Command Line Tools

Homebrew needs a small set of Apple developer tools that are not installed by default. Get them first. Type this and press Return:

xcode-select --install

A dialog box pops up asking if you want to install the tools. Click Install, agree to the license, and wait. The download is large and can take ten or twenty minutes depending on your connection.

If instead you see a message saying the tools are already installed, that is good news. Move on.

You do not need the full Xcode app from the App Store. That is a many gigabyte download you will not use. The command line tools are enough.

3. Install Homebrew

Now install Homebrew itself. Copy this entire line, paste it into the Terminal, and press Return:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

It is one long line. Paste it all at once.

Here is what happens next:

  1. The script prints a list of what it is about to do and pauses. Press Return to continue.
  2. It asks for your Mac password. Type it and press Return. Nothing appears on the screen while you type, not even dots. That is normal and intentional. The password is going in.
  3. It downloads and installs. This takes a few minutes.

When it finishes you will see a line that says ==> Installation successful! followed by a section titled Next steps. Do not close the window. Those next steps matter, and they are the part people skip.

4. Finish the setup so your Mac can find brew

This is the step that goes wrong most often, so go slowly.

Installing a program is not the same as telling your shell where to find it. Your shell looks for commands in a list of folders called the PATH. Homebrew installs itself into a folder that is not on that list yet, so if you stop here, typing brew gives you command not found.

The commands you need are already on your screen. The installer printed them under a heading that says Next steps. Scroll up in the Terminal if they have scrolled past. They are two or three lines starting with echo and eval. Select those lines, copy them, paste them at the prompt, and press Return. Then skip ahead to step 5.

Those lines are written for your specific Mac, so copying them is always the right move. Read on only if you cannot find them.

If you cannot find them, you need to know where Homebrew put itself, which depends on which kind of Mac you have. You do not have to know that. Run this command and let your Mac answer:

ls /opt/homebrew/bin/brew
  • If it prints /opt/homebrew/bin/brew, use Block A below.
  • If it says No such file or directory, use Block B below.

Block A, for Macs with an Apple chip, which is most Macs sold since late 2020:

echo >> ~/.zprofile
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

Block B, for older Macs with an Intel chip:

echo >> ~/.zprofile
echo 'eval "$(/usr/local/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/usr/local/bin/brew shellenv)"

Copy all three lines of your block, paste them at the prompt, and press Return. The only difference between the blocks is the folder name, so if you pick wrong, nothing breaks. You will find out in step 5 and can come back and run the other one.

What those commands do, in plain terms: the first two append a line to ~/.zprofile, a small settings file your shell reads every time it starts. The third runs that same line right now so you do not have to wait. From now on, every new Terminal window will know where Homebrew lives.

Now quit the Terminal completely with Command + Q and open it again. This guarantees the settings file gets read.

5. Check that it worked

brew --version

You should see something like Homebrew 4.x.x. If you do, you are past the hard part.

While you are here, run:

brew doctor

This checks your setup for problems. Your system is ready to brew. means everything is fine. Warnings are usually harmless, but if you get one you do not understand, bring the exact text to class.

6. Install Python

brew install python

Homebrew downloads Python and everything it depends on. Give it a minute.

Check it:

python3 --version

You should see a version number like Python 3.13.0.

Notice that the command is python3, not python. On a Mac, plain python either does not exist or points at Apple's old copy. Get in the habit of typing python3 and you will avoid a whole category of confusing errors.

To run a program you have written, use:

python3 myscript.py

To start the interactive prompt where you can type Python one line at a time, type python3 by itself. Press Control + D to leave it.

Homebrew also installed pip, the tool that installs Python libraries. Same rule applies, use pip3:

pip3 --version

7. Install Git

brew install git

Check it:

git --version

You should see a version number like git version 2.51.0.

If the version looks suspiciously old, your shell is still finding Apple's copy instead of Homebrew's. Quit the Terminal with Command + Q, reopen, and try again. If it is still old, go back to step 4.

8. Tell Git who you are

Git records a name and email with every change you save. Set them once, now, and never think about it again. Use your real name and the email address you use for this course:

git config --global user.name "Ada Lovelace"
git config --global user.email "ada@example.com"

Keep the quotes. Check your work:

git config --global --list

Once this is done, you are ready to set up ssh_keys and start using Git for real.

Using Homebrew from now on

Command What it does
brew install X Install the program X
brew uninstall X Remove X
brew list List everything you have installed
brew update Get the latest catalog of available software
brew upgrade Update everything you have installed
brew doctor Check your setup for problems
brew search X Look for a package named something like X

A good habit is to run brew update && brew upgrade every few weeks.

When something goes wrong

brew: command not found Step 4 did not take effect. Quit the Terminal with Command + Q and reopen it. If that does not fix it, go back to step 4 and run the ls /opt/homebrew/bin/brew test, then paste the block it points you to.

python3: command not found Same cause, same fix. brew and python3 both live in the folder that step 4 adds to your PATH.

The install seems frozen Downloads are quiet. If the cursor is sitting there with no prompt, it is probably still working. Give it several minutes before you worry. Never close the Terminal in the middle of an install.

It is asking for a password and nothing appears when I type That is on purpose. The Terminal hides passwords completely. Type it and press Return.

Anything else Copy the exact command you typed and the exact error message, and bring both to class or office hours. "It didn't work" is very hard to help with. The error text is almost always enough to solve it in under a minute.
