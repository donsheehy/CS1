In this homework, we will make some new additions to our image editing program.

As a reminder, in class we developed the following image filter code. There might be some slight changes from the version from class. Make sure you understand what we did.

from PIL import Image

def posterize(color):
    if sum(color) > 400:
        return (255,255,0)
    else:
        return (0,0,0)

def invert(color):
    r, g, b = color
    return (255 - r, 255 - g, 255 - b)

def filter_image(image_file, filter):
    width, height = image_file.size

    for y in range(height):
        for x in range(width):
            color = image_file.getpixel((x,y))
            image_file.putpixel((x,y), filter(color))

if __name__ == "__main__":
    img = Image.open("shannon.jpg")
    filter_image(img, invert)
    img.save("shannon_filtered.jpg")

Crop an image to make it a square

Let's write a function that takes an image and crops it so that the result is a square.

For this, we can use the crop method. The argument for this method is a tuple of four integers describing the box that you want to keep. For example, mypicture.crop((0,0,100,200)) will crop the image mypicture and only keep the box 100 pixels wide and 200 pixels tall at the top left corner of the image.

This might seem backwards (or upsidedown) the first time you see it. The pixel (0,0) is the topleft pixel in the image. It is counting the rows from the top, starting at 0. This is also the way the raster would work in a cathode ray tube.

For this part of the assignment, write a function called crop_square that crops an image so that the result is a square and it should be as large as possible. You should make sure that the center of the image stays the same. If the width is greater than the height, you will want to crop some of the left and the right. If the height is greater than the width, you will want to crop some of the top and the bottom.

Your function should return a new Image object. Note that Image.crop also creates a new image rather than editing the one you gave it.

Blur an Image

Our image filters that we write previously determined the color of the output as a function of the color of the one current pixel. To blur an image, we will look at the neighboring pixels as well. Write a program that takes an image and produces a new image

You will need to make your own new Image object. For this, we will use the Image.new() function. The arguments are the mode (as a string) and the size (as a tuple). We should stick with "RGB" mode for now.

width, height = (300, 400)
img = Image.new("RGB", (width, height))

To blur the image. set every pixel to be the average of the pixel in the original image and the eight neighboring pixels.

Be careful. When you write this the first time, it is not uncommon to get into trouble at the edges of the image. There is no pixel to the right of any pixel on the right edge. There is no pixel below any pixel on the bottom edge. You will get an IndexError if you try to access such a pixel.

Call your function blur and return the new image.
