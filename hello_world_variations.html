Hello, World! Variations

You already met the classic Hello, World! program in strings_and_print. It turns out that tiny program can be twisted in a dozen directions. Each variation below is a small excuse to preview an idea you'll meet properly later in the course. You don't need to understand every line right now. Just enjoy the ride.

Hello, in a Box

message = "Hello, World!"
border = "*" * (len(message) + 4)
print(border)
print("* " + message + " *")
print(border)

*****************
* Hello, World! *
*****************

The * between a string and a number repeats the string that many times. That's how border becomes a row of asterisks as long as the message, plus four. The + between two strings glues them together. This is called concatenation. Strings support a surprising amount of arithmetic-flavored behavior once you know the tricks.

Hello, Backwards

greeting = "Hello, World!"
print(greeting[::-1])

!dlroW ,olleH

The square brackets after greeting are called slicing. [::-1] is a compact way of saying "give me the whole string, but step through it backwards." We'll cover slicing properly later. For now, just notice that a string can be sliced up and rearranged like a deck of cards.

Hello, Many Times

for _ in range(3):
    print("Hello, World!")

Hello, World!
Hello, World!
Hello, World!

This is a sneak peek at a loop. The line for _ in range(3): means "do the next indented thing three times." The underscore _ is a variable name that Python programmers use when they need a name but don't care about the value. We'll spend a lot of time on loops soon.

Hello, in Many Languages

greetings = ["Hello", "Hola", "Bonjour", "Ciao", "Konnichiwa"]
for greeting in greetings:
    print(f"{greeting}, World!")

Hello, World!
Hola, World!
Bonjour, World!
Ciao, World!
Konnichiwa, World!

Here, greetings is a list, a sequence of values, in this case strings, that live under one name. The loop walks through the list one item at a time, and each time, greeting refers to the next one. The f"{greeting}, World!" part is an f-string. See input_and_fstrings for more on those.

Key Idea: A loop plus a list lets you do "the same thing" to many different values without copying and pasting code.

Hello, You

name = input("What's your name? ")
print(f"Hello, {name}!")

This one needs a keyboard, so I can't run it live on this page. Try it yourself. The input function pauses the program and waits for you to type something and press enter. Whatever you type comes back as a string, which we then drop into an f-string.

Hello, as a Function

def say_hello():
    print("Hello, World!")

say_hello()

Hello, World!

Here, we wrapped our one line of code inside a function named say_hello. Defining the function doesn't print anything by itself. Only the last line, say_hello(), actually calls it and makes the printing happen. This is the same distinction between defining and using that shows up everywhere in programming.

Hello, Encoded

import codecs

secret = codecs.encode("Hello, World!", "rot13")
print(secret)
print(codecs.decode(secret, "rot13"))

Uryyb, Jbeyq!
Hello, World!

The first line imports a module named codecs, a bundle of code someone else wrote that we get to borrow. rot13 is a simple, very breakable code that shifts each letter thirteen places through the alphabet. Encoding it once scrambles it. Encoding it again unscrambles it, since shifting by thirteen twice brings you back to where you started. Every string you've ever printed is, underneath, some scheme for representing text as bits. rot13 just makes that fact visible.

Hello, Numerically

codes = [72, 101, 108, 108, 111, 44, 32, 87, 111, 114, 108, 100, 33]
letters = [chr(code) for code in codes]
print("".join(letters))

Hello, World!

Every character your computer can display is secretly a number. chr converts a number into the character it stands for. Here, we build the whole message one number at a time, then glue the resulting characters back together with "".join(...). This is the same idea as Hello, Encoded, pushed one level deeper. Text is numbers wearing a costume.

Hello, Without the Letter L

Here's a puzzle rather than a variation. Print the exact text Hello, World!, but the letter l may never appear inside a string literal in your code. It can appear anywhere else you like.

Click to reveal. 
l = chr(108)
print("He" + l + l + "o, Wor" + l + "d!")

Hello, World!

The trick is the one from Hello, Numerically. chr(108) produces the character l without ever typing it inside quotation marks. We stash it in a variable, and the variable's name happens to contain the letter l, but that's not a string literal, so it doesn't break the rule.
